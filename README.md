# Markdown Auto Link Text

A VS Code extension that automatically adds heading text as Markdown link text.

見出しのテキストをMarkdownのリンクテキストとして自動的に追加するVS Code拡張機能

### 機能

- 見出しへのリンク作成時、`[]` に元の見出し文字列を自動挿入
- 既にリンク文字列がある場合は変更しない
